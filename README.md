# من سيربح المليون 💰

لعبة أسئلة على طريقة "من سيربح المليون". تشتغل كتطبيق يمكن تثبيته (PWA) على الموبايل واللابتوب، وتشتغل بدون إنترنت بعد أول فتح.

## المميزات
- **982 سؤال** موزعة على 15 مستوى، والسؤال بيصعب كل ما زاد المبلغ (من 100$ للمليون)
- الأسئلة ما بتتكرر: اللعبة بتحفظ الأسئلة اللي طلعت، وما بترجع تطلعها إلا بعد ما تخلص كل أسئلة المستوى
- ترتيب الخيارات بيتغير عشوائياً كل مرة
- وسائل المساعدة: حذف إجابتين (50:50)، رأي الجمهور، اتصال بصديق
- المبالغ المضمونة: 1,000$ و 32,000$
- مؤقت: 30 ثانية للأسئلة 1-5، و45 ثانية للأسئلة 6-10، وبدون وقت بعدها
- إمكانية الانسحاب والاحتفاظ بالمبلغ

## التشغيل
لازم تشغّلها من سيرفر (بسبب ملف JSON والـ Service Worker):
- VS Code ← إضافة **Live Server** ← كليك يمين على `index.html` ← Open with Live Server
- أو: `python -m http.server` وبعدها افتح `http://localhost:8000`

للتثبيت كتطبيق لازم يكون الموقع على HTTPS (مثل Vercel أو Netlify أو GitHub Pages).

## إضافة أسئلة
كل الأسئلة موجودة بملف `questions.json`:

```json
{ "q": "نص السؤال؟", "options": ["الصحيح", "خطأ", "خطأ", "خطأ"], "answer": 0 }
```
- `answer` هو رقم الإجابة الصحيحة جوّا `options` (يبدأ من 0)
- حط السؤال بالمستوى المناسب ضمن `levels` (أول مستوى = 100$، آخر مستوى = المليون)

### الطريقة الأسهل (موصى بها)
- أضف الأسئلة اليدوية بملف `tools/hand_questions.json`، أو زيد جداول المعلومات (عواصم، عملات، كتب...) بملف `tools/build_questions.py`
- بعدها شغّل: `python tools/build_questions.py`
- السكربت بيعيد بناء `questions.json` ونسخته المضغوطة `questions.json.gz` (اللعبة بتقرأ المضغوطة أولاً)، وبيحذف الأسئلة المكررة
- إذا عدّلت `questions.json` بإيدك، احذف `questions.json.gz` أو شغّل السكربت، وإلا اللعبة رح تضل تقرأ النسخة القديمة

⚠️ بعد ما تعدّل الملفات وترفعها، غيّر رقم النسخة بملف `sw.js` (مثلاً `millionaire-v2`) لحتى يوصل التحديث للتطبيق المثبّت.
